AFTERLIGHT v3 — Author's Canon

Это локальный PWA-прототип. Возможности:
- несколько историй;
- канон автора с закреплёнными фактами;
- идеи ИИ отдельно от канона, с ручным принятием/отклонением;
- заметки памяти;
- черновик сцен и ручное редактирование сообщений;
- экспорт и импорт резервной копии;
- цвет акцента и фоновая картинка по ссылке.

Важно:
- реального ИИ-чата пока нет;
- личных аккаунтов и облачной синхронизации пока нет;
- данные хранятся в localStorage браузера;
- не добавляй API-ключи в HTML/JavaScript.
Для реального ИИ и аккаунтов потребуется защищённый сервер.
